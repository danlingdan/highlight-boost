# 行内代码标注 v1

行内代码整体作为一个标注对象。选中其中一部分、整个代码，或将空光标放入代码，都对整段代码应用语义。正文、行内代码和代码块可由同一连续选区一起标记。

## 存储

代码的反引号、空白和内部字符保持原样。标注注释紧贴闭合反引号，跟随 Markdown 保存：

```markdown
比较 `a==b`%%hbi:{"v":1,"id":"inline-example","color":"yellow","semantic":"important","label":"重点"}%% 的结果。
```

字段：

- `v`：格式版本，当前为 1。
- `id`：标注身份。改色保留 ID；编辑复制出来的标注时，为后面的副本分配新 ID。
- `color`：`default`、`red`、`orange`、`yellow`、`green`、`blue`、`purple`。
- `semantic`：预设 ID，或直接颜色操作的 `color:颜色`。
- `label`：应用时的语义名称快照。

JSON 中的 `%` 编码为 `\u0025`，保持注释边界完整。移除标注只删除相邻的标注注释。普通注释和无效元数据继续保留为源文本。

## 编辑与显示

Source 模式显示完整注释，代码内容带有颜色底线和背景。Live Preview 将注释折叠为“行内标注”，点击或按 Enter/空格展开；选区进入注释时显示源文本。阅读视图装饰原有 `code` 元素，保留它的子节点和语法样式。

源码范围与显示值分别保存：源范围包含原有空白及换行；显示值遵循行内代码的 Markdown 规则，换行显示为空格。侧栏摘录选择足够长的反引号，并在需要时添加分隔空格，重新解析后保持显示值。

侧栏显示“行内代码”和来源行号，点击后选择源内容。附着关系由紧邻位置确定：代码被编辑后，相邻标注继续作用于当前整段代码；与代码分离的注释作为源文本保留。

阅读对应结合源行区间、代码显示值及同文出现顺序。同段落中的同文 HTML `code` 等额外节点导致来源歧义时，保留代码原显示；侧栏仍可跳转到准确源位置。
