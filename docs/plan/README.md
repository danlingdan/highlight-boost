# 高亮强化插件调研与计划

调研日期：2026-11-14。项目名称：Highlight Boost。范围涵盖正文、行内代码与代码块。

当前实施范围为桌面端，正式版发布前不承诺移动端支持；正式版之后另行评估。性能测试与优化在功能完成后统一开展。

## 核心结论

Obsidian 1.14 已提供六色正文高亮。项目采用“正文与代码统一的语义标注工作台”定位，以精确编辑、代码行与文本强调、批注、定位和摘录作为完整体验。

代码块是首版主线：在代码中选中 `memcpy` 的参数，可以像正文中的“疑问”一样被分类、批注、检索，并随代码上下文一起摘录。语法着色负责表达语言结构，用户高亮负责表达阅读意图，两者分层呈现。
