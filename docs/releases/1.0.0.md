# Highlight Boost 1.0.0

首个正式版本，支持正文、行内代码与代码块的高亮、批注、检索和摘录导出。适用于 Windows、macOS 和 Linux，面向最新 Obsidian 桌面稳定版，当前为 **1.15.1**。

## 标注与批注

- 正文支持原生颜色与局部改色；行内代码按整段标记；代码块支持整行和精确字符范围，可保留重叠标注。
- 内置重点、疑问、引用、行动四种可自定义预设。选区面板、命令和右键菜单提供相同操作，多选区修改可一次撤销。
- 三类标注均可添加批注。代码变化后按原句与上下文重新定位；无法定位时，可在侧栏将标注绑定到新选区。

## 工作台与摘录

- 在当前笔记、目录、全库或集合中查询，组合类型、语义、颜色、代码语言和路径筛选。
- 卡片显示标题链和代码上下文，支持来源跳转、批注编辑、语义修改和单条移除。
- 复制单条带来源链接的摘录，或使用保留格式、纯文本、引用块、代码围栏四种模板生成摘录笔记。

## 代码展示与迁移

- 可在 Obsidian 宿主着色与内置 Shiki 之间切换，内置模式支持阅读视图和实时预览。
- 支持代码标题、逻辑行号、换行、折叠，以及原始 diff 和变更片段复制。
- 读取 Code Styler、Codeblock Customizer、Hugo 和 Expressive Code 的常见围栏参数。
- Highlightr、Hilo 和围栏行强调支持预览迁移、按文件应用与恢复。

## 桌面交互

支持中英文界面切换、笔记与工作台独立窗口、工具栏键盘操作，以及带标注和代码批注的 PDF 导出。
