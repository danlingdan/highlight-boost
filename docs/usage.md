# 桌面操作说明

## 加载当前构建

构建后，将 `main.js`、`manifest.json` 和 `styles.css` 放入测试笔记库的 `.obsidian/plugins/highlight-boost/`，在第三方插件中启用 Highlight Boost。项目内可运行 `pnpm prepare:vault` 准备隔离测试库。

当前源码版本为 0.1.0，已公开于 GitHub；可安装 Release 与社区上架按阶段 H 发布。

## 标注正文和行内代码

选中文本，在浮动面板选择重点、疑问、引用或行动。也可使用命令面板、快捷键或右键菜单。正文局部选区只修改选中部分；行内代码以整段为单位，内部 `==` 和反引号保持代码含义。

选择颜色只改颜色，保留已有语义。再次应用语义会使用该预设的名称和颜色。多选区共用一次操作，撤销或重做均为一次。

## 标注代码块

选中函数名、参数或表达式，在面板选择语义。选择“整行”后，同一操作扩展到所在代码行；“代码行”命令也可用于空光标所在行。面板显示代码块序号及逻辑行范围。

标注写在围栏外，代码内容保持原样。跨正文和多个代码块的选区按各自对象处理，仍可一次撤销。不同范围的代码标注可以重叠；从侧栏修改或移除某一条时，只处理该条记录。

## 使用选区面板

面板默认自动出现；在设置中关闭后，仍可执行“打开选区面板”。方向键、Home/End 移动按钮焦点，Enter 执行，Escape 关闭并回到编辑器。点击面板外部也会关闭。最近三种成功使用的颜色保留在设置中。

## 从侧栏回到原文

打开“当前笔记重点”，按原文、名称或代码语言搜索，并组合类型、语义筛选。卡片显示标题链；代码卡片可展开相邻行上下文。

点击卡片摘录定位到准确源范围。Source 保持 Source；Live Preview 保持 Live Preview；从阅读视图点击后进入 Live Preview，并选中相应正文或代码。跳转本身不修改笔记。

代码被改写而暂时无法定位时，卡片保留原摘录。在原代码块中选中新位置，再点击“绑定到当前选区”恢复锚点。

## 复制代码与摘录

“复制当前代码块”输出逻辑代码文本，移除容器前缀并使用 LF 换行。内置代码组件也提供复制按钮。

卡片“复制摘录”保留精确标注内容，附来源链接、语义名称、标题链和代码块内行号。代码摘录补充前后一行上下文；围栏长度按代码内容选择，代码里的反引号围栏保持字面含义。已有块 ID 优先用于链接，其次使用所在标题，链接格式跟随笔记库设置。

## 跨笔记检索

执行“高亮工作台”，或在侧栏切换范围。当前目录包含当前笔记所在目录及其子目录，全库覆盖源 Markdown 笔记。正文、行内代码和代码块出现在同一结果中；类型、语义、颜色、代码语言、路径和搜索可组合使用，结果可按来源或语义分组。

点击跨笔记条目会打开对应笔记并选中源范围。命令入口会重置检索条件；在范围下拉框中切换会保留当前条件。工作台显示索引笔记数，读取失败时显示数量，点击“重建索引”重新读取。

## 编辑说明

从卡片点击“编辑批注”，输入多行说明并保存；取消会保留原文。清空内容再保存即可移除说明。源条目或已有批注在对话框打开后发生变化时，输入草稿继续保留，可刷新条目后重新编辑。

正文使用标准脚注，行内代码和代码块使用关联批注。改色、改语义和重新绑定会保留说明；局部拆分的正文片段共用原脚注。移除正文高亮仍保留标准脚注；移除代码标注同时移除该条记录及其批注。

Live Preview 将 HB 脚注引用及定义收为可展开摘要，Source 显示完整源文。阅读视图显示正文脚注，代码组件下方可展开说明。代码复制继续只输出代码。批注文本可检索，也会进入集合快照和摘录笔记。

## 保存集合

点击“新建集合”输入名称，再从卡片“加入集合”选择目标。重复加入同一条目只保留一条引用。切换到集合范围后选择名称，可以继续筛选、复制、生成摘录，或从集合移除条目。

源标注可定位时，集合显示当前内容；源文件删除或标注变化后，保留加入时摘录并显示待定位状态。文件和目录改名会更新集合路径。删除集合与移除引用均保持源笔记原样。

## 生成摘录笔记

选择保留格式、纯文本、引用块或代码围栏模板，点击“生成摘录笔记”，将当前过滤结果写入 `Highlight Boost/`。摘录保留来源信息，点击链接可回到对应源笔记的块或标题。

生成笔记带导出标记，不会再次进入源索引。它保存生成时的快照；再次生成会创建新笔记。模板选择和集合保存在插件配置中。

## 视图和设置

Source 显示完整标注注释；Live Preview 将其收为可展开按钮；阅读视图隐藏注释并显示重点。点击或使用 Enter/空格可展开元数据按钮。

界面语言支持跟随 Obsidian、中文和 English，即时生效。自定义预设和已有名称快照保持原文。四种语义可改名、改色，并可指定默认语义；恢复默认预设保留界面语言、语法提供者和面板选项。

语法着色可选择宿主或内置 Shiki，更改后重新启用插件。内置模块的来源和特别感谢见 [第三方声明](../THIRD_PARTY_NOTICES.md)。
