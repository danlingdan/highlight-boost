# 代码标注 v1

状态：2026-11-14 冻结首个可用版本的写入格式。版本号为 `v: 1`，格式由 HB 解析、序列化和编辑核心共同实现。

## 存储位置

元数据放在围栏前一行，与围栏保持相同容器层级。代码内容、围栏字符和语言参数保持原样。

````markdown
%%hb:{"v":1,"blockId":"block-example","marks":[{"id":"mark-example","kind":"text","from":0,"to":3,"quote":"mov","prefix":"","suffix":" ax, bx","color":"yellow","semantic":"important","label":"重点","occurrenceCount":1}]}%%
```asm
mov ax, bx
```
````

顶层注释不带前缀。引用与 callout 使用 `> ` 前缀；列表首行可以写列表标记，围栏及后续代码使用对应缩进。解析时将列表标记转换为同宽缩进后核对容器身份。

## 字段

| 对象 | 字段 | 含义 |
| --- | --- | --- |
| 块 | `v` | 当前为整数 1 |
| 块 | `blockId` | 独立代码块身份，新建时生成 UUID |
| 块 | `marks` | 该块的标注数组 |
| 标注 | `id` | 标注身份，新建时生成 UUID |
| 标注 | `kind` | `text` 精确文本，或 `lines` 整行 |
| 标注 | `from` / `to` | 块内逻辑文本的 UTF-16 左闭右开范围 |
| 标注 | `quote` | 创建或重新绑定时的代码摘录 |
| 标注 | `prefix` / `suffix` | 前后各最多 32 个 UTF-16 单元的上下文 |
| 标注 | `color` | `default` 或六种显式颜色 |
| 标注 | `semantic` | 语义预设 ID，或 `color:颜色` |
| 标注 | `label` | 最近应用语义时的名称快照 |
| 标注 | `occurrenceCount` | 可选；创建时原句在该块中的出现次数 |

逻辑代码使用 LF 分隔行，Tab 和 emoji 按原始 UTF-16 单元计数。文件的 CRLF、容器前缀、空白和代码字符在编辑中保留；纯代码复制使用解析得到的逻辑代码文本。整行范围包含行内容，末尾不额外计入下一行。

元数据为单行 JSON；序列化将 `%` 编码为 `\u0025`，使代码中的 `%%` 保持在字段内部。范围必须为非负安全整数且 `to >= from`。旧锚点可超出当前代码长度，解析后通过原句与上下文判定位置。

## 编辑和恢复

- 相同范围和粒度再次应用时更新原记录，保留标注 ID。
- 不同范围的标注可交叠，各自保留身份。
- 直接改色保留已有语义及名称快照。
- 选区移除会移除命中的代码标注；侧栏“移除此条标注”按 ID 删除指定记录。
- 编辑器变更后，用原句、前后文及出现次数重定位，状态为已定位、歧义或缺失。
- 原句改写后，保留原摘录；在同一代码块重新选择位置，通过侧栏绑定并保留身份。
- 复制的块可携带相同 ID；编辑后面的副本时为它分配新块 ID 和标注 ID。

标注随笔记保存。Source 显示注释；Live Preview 将它折叠为可展开按钮；阅读视图隐藏注释并增强原代码输出。未知版本或无效 JSON 保留为源文本，不作为 v1 标注读取。

## 容器映射对照

下表中代码文本均为 `mov ax, bx`；行列从 1 开始。

| 原文形态 | 代码所在原文位置 | 对应逻辑位置 |
| --- | --- | --- |
| 顶层围栏 | 开围栏下一行，第 1 列 | 第 1 行，第 1 列 |
| `> ` 引用或 callout | 代码行第 3 列 | 第 1 行，第 1 列 |
| `- ` 列表，后续缩进两格 | 代码行第 3 列 | 第 1 行，第 1 列 |

解析结果为每一逻辑行保存原文范围；UTF-16 偏移通过这些范围往返映射。对应固定样例见 `tests/core.test.ts`、`tests/persistence.test.ts` 和 `tests/mixed-selection.test.ts`。
