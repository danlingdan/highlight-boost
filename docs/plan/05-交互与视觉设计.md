# 交互与视觉设计

## 1. 统一入口

命令面板、编辑器右键菜单、可选选区浮动面板、移动工具栏共享同一动作服务。用户可为命令配置快捷键；初始配置使用宿主快捷键体系。

命令包括：应用语义、设置颜色、移除标注、标记所选代码行、标记代码文本、添加批注、打开当前笔记重点、查找全部重点、复制摘录。命令使用 editorCallback / editorCheckCallback 根据当前上下文提供对应操作。

浮动面板默认按设置启用；固定预设、最近使用和更多颜色分区展示。面板开启时保存源选区，点击颜色后保留逻辑选区，方便连续改色。点击空白或 Escape 关闭，焦点回到编辑器。

## 2. 正文流程

选中概念 → 选择“重点” → 原生高亮出现 → 侧栏即时新增条目。光标位于高亮内部时可改语义、批注或移除。局部选择操作只作用于所选内容。

原生高亮色板与 HB 面板分别承担颜色编辑、语义操作；设置中可以选择主要入口。读取普通原生高亮时显示颜色名，创建持久语义时显示语义名。

## 3. 代码流程

选中代码参数 → 面板显示“文本 / 整行” → 选择“疑问” → 代码出现底线或背景 → 添加说明。整行模式同时标出左侧语义边条。面板明确当前对象是第几个代码块及逻辑行范围。

跳转代码条目时展开折叠、滚动到对应逻辑行，短暂强调准确字符。默认只移动焦点；编辑动作从命令或菜单继续发起。代码悬浮按钮安排为复制、标注、更多，窄窗口折叠为一个菜单。

## 4. 统一侧栏

顶部显示范围：当前笔记、当前目录、全库、集合。检索框支持正文和批注文本；类型、语义、颜色、语言、路径为独立过滤器。首版先完成当前笔记，其余范围随后集成。

卡片包含对象图标、语义名称、内容预览、标题链、来源文件及代码行号。代码预览保留等宽字体和语言标识，展开后展示上下文。操作包括跳转、改语义、批注、复制摘录及加入集合。

按原文顺序、笔记或语义分组。搜索结果显示过滤条件和计数；空状态区分“当前范围没有条目”和“过滤后没有匹配”。锚点待重新定位时，卡片展示原摘录并提供“重新定位”动作。

## 5. 主题与可访问性

使用宿主 CSS 变量及 `hb-` 命名空间。背景强调优先采用透明色，保留代码语法前景；可选择底线、左侧边条和轮廓。浅色、深色和高对比预设分开配置。

语义以名称、图标和颜色共同表达。按钮具备可读名称，面板支持方向键、Enter 与 Escape，焦点状态清晰。触控目标拟定 44 CSS px，窄屏使用底部面板；最终尺寸通过移动验收调整。

按 [WCAG 文本对比要求](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) 设置普通文字 4.5:1、较大文字 3:1 的设计检查目标。颜色计算使用合成后的背景，与真实主题截图配合验证。动效尊重 reduced motion。

## 6. 设置分组

通用项置顶，其余按语义预设、正文、代码、侧栏、摘录模板、兼容及导入分组。代码项包括重点样式、行号、折叠、标题、语法提供者、排除语言和默认选区粒度。

设置旁给出简短效果说明和预览。例如“代码复制：只复制代码内容”“标记方式：精确文本 / 整行”。中英文文案由 i18n key 管理，枚举和命令名保持一致。

## 7. 移动与多窗口

移动端以命令及工具栏为主，长按条目打开操作面板。软键盘弹出后保留目标选区，面板适应可视视口。页面旋转、分屏、缩放和文本选择手柄进入验证集。

弹出窗口和独立设置窗口使用所属 document 创建元素，样式注入及事件跟随各自窗口生命周期。侧栏各实例共享索引，通过独立 UI 状态保留筛选和展开位置。
