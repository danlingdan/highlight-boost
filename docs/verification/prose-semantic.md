# 正文持久语义实现与验证

日期：2026-11-14。桌面原型 0.1.0，Obsidian 1.15.0 运行包及 Electron 38.8.6。

## 本轮交付

正文继续采用原生颜色格式，以相邻 `hbp` v1 注释保存持久 ID、语义 ID 和名称快照。局部应用语义、拆分、合并和移除同时更新正文及元数据；直接改色保留已有语义。行内代码和代码块也统一了直接改色规则。

侧栏区分同色异义条目，展示保存的名称快照，定位到正文内容。统一条目暴露 `semantic` 和 `markId`。Source 显示原文，Live Preview 提供正文注释折叠，阅读视图沿用原生高亮。

字段与规则见 [正文 v1](../formats/prose-v1.md)。旧原生颜色高亮在读取时保持原样，应用语义时再写入标注。
