# Highlight Boost 1.0.0

Highlight Boost 首个正式版本，将正文、行内代码和代码块中的阅读重点统一管理：标记、批注、检索，再生成带来源的摘录。

## 标注与编辑

- 正文支持原生高亮颜色与局部选区改色。重点、疑问、引用、行动四种语义预设可自行改名改色。
- 行内代码以整段为单位标注；代码块支持整行和精确字符范围，不同范围可重叠。
- 浮动选区面板、命令与右键菜单共用编辑操作。多选区、跨正文与代码的操作可一次撤销和重做。
- 正文、行内代码和代码块均可添加批注；代码修改后可通过来源上下文定位，或从侧栏重新绑定。

## 工作台与摘录

- 在当前笔记、目录、全库和集合中查找重点，组合搜索、类型、语义、颜色、语言和路径筛选。
- 卡片提供标题链、代码上下文、语义修改、批注编辑、单条移除及精确来源跳转。
- 支持复制单条摘录，以及保留格式、纯文本、引用块、代码围栏四种摘录笔记模板。
- 每页显示 50 条结果，查询计数、搜索和导出使用完整命中集。

## 代码展示

- 可选择宿主语法着色或内置 Shiki；内置模式支持阅读视图和 Live Preview。
- 支持代码标题、逻辑行号、起始行号、换行、折叠，以及原始 diff / 变更片段复制。
- 读取 Code Styler、Codeblock Customizer、Hugo 和 Expressive Code 的通用围栏参数，保留源参数。
- 纯代码复制保持代码内容与空白，输出逻辑代码文本，使用 LF 换行。

## 迁移与桌面交互

- Highlightr、Hilo 和围栏行强调可先预览再导入，按文件应用与恢复；恢复记录在重启后继续可用。
- 中文 / English 界面即时切换，自定义语义名称保留原文。
- 支持笔记与工作台独立窗口、窗口布局恢复、工具栏键盘操作，以及带标注和完整代码批注的 PDF 导出。

## 安装与数据

目标平台为 Windows、macOS 和 Linux，基线为 Obsidian **1.15.1**；后续版本跟随最新桌面稳定版。插件 ID 为 `highlight-boost`。

将同一版本的 `main.js`、`manifest.json`、`styles.css` 放入 `.obsidian/plugins/highlight-boost/` 后启用，或解压安装 ZIP 中的 `highlight-boost/` 目录到插件目录。社区目录已提交，收录后可从 Obsidian 内安装。

正文颜色使用原生格式；语义与代码标注使用隐藏注释，正文说明使用脚注。代码块标注保存在围栏外。设置保存预设与集合。本版本采用 v1 标注格式与配置 schemaVersion 2，详见[格式说明](https://github.com/danlingdan/highlight-boost/blob/main/docs/formats/README.md)。

`0.1.0` 是研发候选编号。已有候选笔记继续使用相同标注格式，`1.0.0` 的版本调整没有引入数据格式迁移。

## 验证依据

首发功能的阶段 G 验收基于 Obsidian 1.15.1 / Electron 43.8.9：Windows、macOS 和 Linux 各通过 **36 个场景、1112 项检查**；Windows 扩展主题与插件矩阵通过 **120 个单元、970 项检查**。工程逻辑 / DOM / 引擎测试为 **200 项**，并包含 **500 组解析差分**。

上述数据对应[阶段 G 已归档的源码与运行结果](https://github.com/danlingdan/highlight-boost/blob/96dccbaafbb4cc9fb9803e7c7addbe0fa8525ff2/docs/verification/phase-g-matrix.md)。`1.0.0` 的版本调整、项目目录整理及本次检查单独记录在[发布准备页](https://github.com/danlingdan/highlight-boost/blob/main/docs/releases/README.md)，下载安装测试由维护者执行。
