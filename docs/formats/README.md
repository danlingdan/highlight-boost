# 标注与配置格式

| 对象 | 颜色与语义存储 | 格式 |
| --- | --- | --- |
| 普通正文高亮 | Obsidian 原生 `==` 与颜色 emoji | 无额外注释 |
| 正文语义 | 原生颜色 + 紧邻 `%%hbp:...%%` | [正文 v1](prose-v1.md) |
| 行内代码 | 闭合反引号后紧邻 `%%hbi:...%%` | [行内 v1](inline-v1.md) |
| 围栏代码 | 同容器、围栏前一行的 `%%hb:...%%` | [代码 v1](code-v1.md) |

预设 ID 与标注 ID 分别表达语义类别和记录身份，名称快照随笔记保存。配置目前使用 schemaVersion 3，与笔记中的 `v: 1` 独立；代码资源配置见[代码配置](code-settings.md)。

范围按 UTF-16 代码单元计算，各格式页面列出容器附着、转义和编辑规则。未知版本的注释按普通源文本保留。

全库集合和导出选项保存在插件配置中，见 [集合与索引配置](collections.md)，不改变笔记 v1 字段。

批注沿用 v1，通过可选的 `note` 和 `noteRef` 字段保存。标准脚注和继承规则见 [批注格式](annotations.md)。

展示配置与标注格式独立。围栏参数、全局默认值、会话折叠和 diff 复制规则见 [代码展示与 diff](code-display.md)。

第三方围栏参数直接参与展示，语义元数据独立保存。字段优先级、行选择规则、扩展字段与样例见 [参数对照](fence-parameters.md)。

Highlightr、Hilo 与代码行参数可通过独立窗口迁移，预览和逐文件恢复格式见 [迁移说明](migration.md)。迁移记录独立于笔记 v1 和插件配置版本。
