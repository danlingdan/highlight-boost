# 阶段 A 第二轮验证

日期：2026-11-14。阶段 A 继续实施，当前原型版本为 0.1.0。

## 本轮完成

### A01：默认色与六色

新增默认色、红、橙、黄、绿、蓝、紫七个命令，以及可搜索的颜色选择面板。正文使用原生语法，代码使用相同颜色记录标注；四种语义命令继续保留。

在真实 Obsidian 阅读视图中逐项检查写入结果和 `mark` 的颜色属性。原生默认色的 `data-highlight` 为空字符串，显式黄色为 `yellow`，其余颜色分别对应各自名称。数据模型继续区分 default 与 yellow。

### A04：复制代码块、重复原句与重新绑定

- 在复制块上执行编辑时，为副本分配新的块 ID 和标注 ID，原块保持原样。
- 侧栏条目带有所属代码块身份，复制块中的同名标注能分别操作。
- 新标注记录原句出现次数；原句原本重复、上下文消失时，剩余同文进入待定位状态。
- HB 元数据与围栏按容器前缀关联，引用内元数据与顶层代码块分别处理。
- 代码改写后，先选中同块中的新位置，再点击侧栏“绑定到当前选区”。身份、颜色和语义保留，绑定可单次撤销及重做。

纯逻辑测试核对副本 ID、原句歧义、容器关联、重新绑定与代码文本保持一致；宿主测试通过侧栏执行实际绑定，并检查选区与撤销历史。

### A06：元数据折叠与编辑入口

Live Preview 将 HB 注释收起为“代码标注 · N 条”。鼠标点击或按 Enter/空格展开并选中元数据；光标或选区进入元数据时显示原文，离开后重新收起。Source 模式显示完整注释。

折叠只改变编辑器装饰，逻辑偏移和源文本保持一致。已验证编辑器状态变更、鼠标及键盘展开、Source 模式切换和代码标注撤销。输入法组合输入及更多光标边界继续补充。
