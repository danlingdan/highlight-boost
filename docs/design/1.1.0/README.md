# 1.1.0 第一阶段：交互与视觉定稿

日期：2026-11-16。

## 交付物

- [交互样稿](index.html)：本地打开，切换深浅主题、280 / 360 / 600 / 1080 px 宽度与八类场景。
- [界面规范](interface.md)：组件、状态、入口、主题变量与键盘规则。
- [代码接入规范](code-integration.md)：代码块归属、参数、配置迁移与视图规则。
- [代码能力矩阵](code-capabilities.md)：上游能力、当前差距、实现入口与验收样例。
- [固定样例](code-fixtures.md)：第二阶段沿用的输入数据。
- [第一阶段验证记录](../../verification/1.1.0/phase-1/README.md)：来源、基线探测、样稿检查与截图。

样稿展示最终界面与交互，不修改笔记、配置或剪贴板。插件功能实现在第二、三阶段进行。

## 定稿决策

1. 统一代码着色基础与展示模型，用户设置只表达外观和行为。
2. 采用轻量原生风格：主题变量、局部语义色、统一卡片与分层控件。
3. 标注、批注、集合和摘录共享条目动作，当前笔记与全库共用工作台。
4. 完整承接 Shiki 的语言、主题、自定义语法、行内代码与 Expressive Code 展示能力。
5. 代码接管采用源区段匹配与普通代码后处理，专用块按语言归属继续交给对应处理器。
6. 配置升级为 schema 3，移除 `syntaxProvider`，保留现有笔记格式和展示开关。

## 查看方式

直接在浏览器打开 `index.html`。顶部控件属于设计预览，插件内只显示画布中的组件。

侧栏与宽版工作台、选区工具栏、代码组件、批注面板、摘录面板、设置预览和组件状态均可切换。可以试用标注语义、精确 / 整行、筛选、搜索、批注保存 / 取消、加入集合、整块 / 局部折叠和摘录模板。

截图保存在验证目录；全尺寸检查图与浏览器配置保存在 `scripts/paths.cjs` 的 `design` 路径，即 `.local/design/1.1.0/`。
