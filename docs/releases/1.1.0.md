# Highlight Boost 1.1.0

## 代码着色与展示

- 代码块自动使用离线语法着色。实时预览和阅读视图使用同一套标题栏、行号、换行、折叠和复制操作。源码编辑时继续显示语法、行号与 diff 背景。
- 深色和浅色模式可分别选择代码主题，也可从笔记库加载本地主题和 TextMate 语法。行内代码可用 `{ts}` 等前缀声明语言。Mermaid 和查询块继续由各自的处理器渲染。
- 围栏可指定终端框、逻辑起始行号和局部折叠。文本、正则和行范围参数生成的强调可与手动标注同时显示。diff 可复制原始补丁或保留新增行与上下文的变更片段。
- 调整行号时，打开的代码块直接更新编号并保留着色和展开状态。

## 标注与整理

- 从选区工具栏或工作台卡片可以编辑批注、加入集合。工作台把搜索、筛选和结果操作放在同一视图，跨窗口定位会回到对应的来源笔记。
- 在工作台点击“生成摘录”，可先选择模板、查看条数和预览，再复制结果或生成笔记。摘录覆盖完整筛选结果，列表翻页只改变屏幕上的卡片。
- 应用迁移后，可以直接在工作台查看本次处理的文件。迁移历史仍提供逐文件恢复。

## 升级

适用于 Obsidian 桌面版 1.15.1。在 Obsidian 的第三方插件界面更新，或手动替换同一版本的 `main.js`、`manifest.json` 和 `styles.css`。

插件首次加载时自动转换旧配置，不需要选择着色来源。已有展示设置、笔记标注、批注、预设和集合可继续使用。如果想调整配色或代码框样式，打开“设置 → Highlight Boost → 代码展示”。[使用说明](https://github.com/danlingdan/highlight-boost/blob/1.1.0/docs/usage.md) · [代码资源配置](https://github.com/danlingdan/highlight-boost/blob/1.1.0/docs/formats/code-settings.md)
