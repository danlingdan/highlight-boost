# 1.1.0 第二阶段：统一代码与配置

日期：2026-11-17。

结果：工程检查通过，34 个测试文件 / 224 项测试通过；31 组宿主场景 / 941 项检查通过，场景错误为零。统一代码专项为 176 项，多窗口及新进程恢复为 39 项。

## 实现

- 默认启用统一语法引擎，移除 `syntaxProvider`、提供者设置及切换后的重启提示。
- 配置升级为 schema 3，保留预设、语言、最近颜色、集合、摘录模板和原有八个代码展示字段，增加 `codeSyntax` 与框架配置。
- 普通代码按源区段后处理，特殊字符与中文语言名、未知语言、ANSI、Callout、列表和引用使用同一代码模型。图表、查询和排除语言保持专用归属。
- 实时预览展示态使用代码组件，选中或点击编辑后回到源代码；字符和整行标注、批注、撤销及代码复制继续工作。
- 接入全部内置语言、别名与主题，自定义 VS Code 主题及 TextMate 语法支持库内目录、别名、嵌入依赖和重新加载。
- 代码框、终端框、无框、行号、换行、diff、行与文本 / 正则强调、整块与局部折叠使用统一参数。复制从源代码读取，ANSI 转义、注释和空白保留。
- `{lang} code` 行内代码在展示态隐藏声明并着色，源模式保留完整原文；空白填充与换行规范化后仍映射到正确源字符。
- 设置、CSS 与本地资源重载串行执行，打开的视图同步更新；各窗口的样式、观察器、定时器和编辑器引用按生命周期释放。

源入口：`src/syntax/`、`src/reading-view.ts`、`src/rendering.ts`、`src/code-display.ts`、`src/code-options.ts`、`src/settings.ts` 与 `src/main.ts`。

## 回归中修复

- 避免将已经接管的代码组件当作未匹配原生代码清理，保留标题栏与展示状态。
- 组件归属限定到创建它的阅读处理器，避免重复处理与交叉卸载。
- 从侧栏跳转时同步已有组件的整块展开状态，局部折叠状态随组件重建恢复。
- 已接管区段的原文变化后按当前区段重建组件，卸载时恢复当前代码内容。
- 正则拆分保留字符组与空格，同时识别以斜杠开头的文件标题。
