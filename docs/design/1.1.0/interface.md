# 界面与交互规范

## 1. 视觉变量

样稿中的浅色与深色值是设计预览色板。实际插件映射到 Obsidian 主题变量，不固定覆盖主题颜色。

| 项目 | 规格 | Obsidian 映射 |
| --- | --- | --- |
| 主表面 / 次表面 | 工作台、卡片 / 分组、代码背景 | `--background-primary` / `--background-secondary`、`--code-background` |
| 边框 / 悬停 | 1 px 分隔，悬停调整局部表面 | `--background-modifier-border` / `--background-modifier-hover` |
| 主 / 次 / 辅助文字 | 摘录和操作 / 来源和说明 / 索引时间 | `--text-normal` / `--text-muted` / `--text-faint` |
| 主操作 / 焦点 | 生成、保存与选中指示 | `--interactive-accent` / `--text-on-accent` |
| 间距 | 4、8、12、16、24 px | `--hb-space-1/2/3/4/6` |
| 圆角 | 控件 6 px、卡片 10 px、面板 14 px | `--hb-radius-sm/md/lg` |
| 控件 / 图标 | 常规 32 px 高、紧凑操作 28 px、图标 16 px | `--hb-control`、`--hb-icon` |
| 文字 | 标题 16 px，主文 14 px，来源 12 px，辅助标签 11 px | 界面字体；代码使用 `--font-monospace` |
| 焦点 | 2 px 轮廓，3 px 外偏移 | `--hb-focus` 映射主题强调色 |
| 阴影 | 仅工具栏、菜单和弹出面板 | 主题阴影或主文字色 12% 的柔和阴影 |

重点 / 疑问 / 引用 / 行动使用预设颜色，并配合名称与图标。背景采用语义色 12%—22% 的透明混合；语法 token 保留前景色。卡片使用中性底色，选中时增加强调色边框与 4% 的背景混合。

普通文字对比度目标为 4.5:1；焦点与非文本控件为 3:1。自定义高亮颜色按合成背景检查； reduced motion 下使用即时状态切换。

## 2. 入口与布局

| 组件 | 入口 | 布局与行为 |
| --- | --- | --- |
| 工作台 | Ribbon、当前笔记命令、全库命令 | 一个视图类型；命令选择对应范围，视图内切换范围保留查询 |
| 选区工具栏 | 编辑器选区自动出现、命令、右键 | 语义为主操作；代码显示精确 / 整行；完成后就近继续批注或加入集合 |
| 批注 | 工具栏、条目卡片、代码批注摘要 | 原文摘要、来源、输入、保存与取消共用同一面板 |
| 摘录 | 工作台结果栏、集合结果栏 | 完整结果数量、格式、预览、复制、生成笔记 |
| 代码展示 | 普通围栏代码、行内语言标记 | 统一着色；代码框、终端框、无框和自动框架共用展示选项 |
| 设置 | Obsidian 插件设置 | 标注与工具栏、代码展示、工作台与摘录、语言与数据 |
| 迁移 | 命令、语言与数据分组 | 保留独立向导，完成后按本次成功文件查看结果 |

### 工作台

顶部依次为范围、来源、搜索、筛选、结果操作和条目。类型、语义、颜色、语言和路径收进展开区；活动筛选显示为可移除标签。分组支持按来源与语义；分页沿用 50 条，数量与导出使用完整查询结果。

集合选择与新建 / 删除只在集合范围出现。重建索引进入工作台更多菜单。删除集合保留源笔记与标注，关闭工作台再打开时恢复范围、查询、页码、展开项与滚动位置。

280 px 使用 12 px 内边距、筛选单列；360 px 使用 16 px 内边距、筛选双列；600 px 增加预览长度，卡片仍按阅读顺序排列。完整宽版样稿为 1080 px，正文与 360 px 工作台并排；可用宽度不足 760 px 时按单列排列。插件实际布局以所属容器宽度计算。

搜索、路径、标题和批注允许断行；来源路径单行省略并提供完整 tooltip。代码在自己的区域内滚动，开启换行时按逻辑行折行。菜单以所属窗口可视区域为边界，靠边时向内展开。

### 卡片

头部显示语义和内容类型，主体显示正文或代码；代码带逻辑行号，展开时增加上下文。批注默认摘要，来源显示文件、标题链与代码行号。定位、批注、复制保持可见；改语义、改颜色、集合、移除进入更多菜单。

同一条目的选择、展开和菜单状态以稳定条目标识保存，重新排序后仍对应原条目。搜索刷新保留输入焦点和插入点。

### 工具栏

正文、行内代码、代码和混合多选区共享四种语义与颜色。只有代码显示精确 / 整行；混合选区显示对象和数量。已有重叠标注先列出候选摘要，选择条目后再编辑。应用标注不自动打开批注。

### 设置

代码展示分为布局、配色和语法：布局包括行号、起始编号、行号字体、框架、标题、换行、整块折叠和 diff；配色包括深浅主题、自定义主题目录和优先使用代码主题颜色；语法包括行内着色、自定义语言目录、排除语言和重新加载。

预览同时含函数着色、字符标注、整行标注、批注与长路径标题。调整设置即时更新预览及打开的视图，不重新启用插件。预设改名改色并排显示。工作台与摘录分组设置默认模板；语言与数据包含中英文、导入迁移与来源许可。

## 3. 组件状态

| 状态 | 呈现与动作 |
| --- | --- |
| 默认 / 悬停 | 中性边框；局部悬停表面和按钮反馈，操作不挤动内容 |
| 选中 | 强调边框，保留文字与代码布局；语义颜色独立 |
| 焦点 | 可见轮廓，不用颜色独自表示选中或错误 |
| 展开 | `aria-expanded` 对应实际内容，文本和位置保留 |
| 处理中 | 触发按钮禁用并显示进行状态，其余可用操作继续使用 |
| 复制成功 / 失败 | 按钮就近反馈，成功约 2 秒后恢复；失败提供重试 |
| 尚无标注 | 说明如何选中并标注，提供工具栏入口 |
| 无匹配 | 保留当前查询，提供清空筛选 |
| 空集合 | 提示从工具栏或卡片加入，提供当前笔记入口 |
| 未打开笔记 | 提供打开笔记或切换全库入口 |
| 待定位 | 显示快照与批注，在有效代码选区提供重新绑定 |
| 索引失败 | 显示失败数量和对应文件，允许重试失败项 |
| 批注草稿 / 冲突 | 显示未保存状态；源条目变化时保留输入，刷新后继续编辑 |

## 4. 焦点与状态归属

- 工具栏支持方向键、Home / End、Enter / Space，Escape 关闭并返回原编辑器选区。
- 菜单支持方向键与 Escape；按 Tab 遵循自然顺序。禁用控件不参与动作。
- 批注与摘录面板使用 Obsidian Modal，限制焦点在面板中；取消、保存或关闭后回到触发控件。触发条目已被删除时回到结果栏。
- 多选区标注是一次撤销；后续批注保存是独立编辑。取消不改变原文。
- 工作台实例分别保存范围、筛选、来源视图、滚动与展开项；预设、主题、索引与集合全局共享。
- 所有弹层、事件、定时器、焦点和样式归属各自的 `ownerDocument`；关闭窗口释放资源。
- 中文组合输入期间暂停标注，输入完成后按当前选区继续。

## 5. 摘录规则

打开面板时读取当前完整查询快照，显示条目数、范围和活动条件。模板切换只重建预览；复制与生成使用同一快照和格式化结果。面板显示期间查询或源文改变时提示刷新结果，由用户选择刷新或保留当前快照。

预览分页或截断时明确提示预览范围，总数仍显示完整数量。四种模板保留现有来源链接、标题链、代码语言、上下文和批注规则。生成带导出标记的新笔记，并提供打开入口。
