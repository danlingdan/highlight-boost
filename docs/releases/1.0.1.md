# Highlight Boost 1.0.1

## 修复

- 停用或重新加载插件时保留高亮工作台的窗口位置，重新启用后恢复原布局。
- 设置页接入 Obsidian 设置搜索；切换语言和恢复预设时使用新的刷新接口，设置名称与控件同步更新。
- 代码组件样式随 `styles.css` 加载，限定到 HB 组件；切换语法提供者和关闭窗口时释放对应交互资源。
- 编辑器定时器与着色动画绑定到所属窗口，修正弹出窗口中的调度与清理。
- 迁移历史读取时校验状态数据，保留逐文件恢复行为。

## 构建与发布

- 内置语法和主题数据去重压缩，首次使用时按需解压；保留原有语言支持和离线着色。
- 发布文件由 GitHub Actions 从版本标签构建，并提供构建来源证明。
- Release 附件统一为 `main.js`、`manifest.json`、`styles.css`。许可保留在源码及构建文件中。

标注格式与配置格式保持不变，更新后继续使用已有标注、批注和集合。
