# 首个可用版本的标注格式

2026-11-14 冻结 v1 持久字段及附着规则，覆盖阶段 D 的正文、行内代码和围栏代码闭环。

| 对象 | 颜色与语义存储 | 格式 |
| --- | --- | --- |
| 普通正文高亮 | Obsidian 原生 `==` 与颜色 emoji | 无额外注释 |
| 正文语义 | 原生颜色 + 紧邻 `%%hbp:...%%` | [正文 v1](prose-v1.md) |
| 行内代码 | 闭合反引号后紧邻 `%%hbi:...%%` | [行内 v1](inline-v1.md) |
| 围栏代码 | 同容器、围栏前一行的 `%%hb:...%%` | [代码 v1](code-v1.md) |

预设 ID 与标注 ID 分别表达语义类别和记录身份，名称快照随笔记保存。配置目前使用 schemaVersion 2，与笔记中的 `v: 1` 独立。

冻结内容为当前字段、UTF-16 范围、容器附着、转义和编辑规则。后续批注、迁移或扩展需要新增持久字段时，补充格式决策、旧笔记读取样例和往返测试，再确定沿用版本或迁移版本。当前读取器将未知版本作为普通源文本保留。

格式验证包括解析与序列化、改色和撤销、容器映射、重复 ID、重新绑定及独立进程恢复。运行证据见 [阶段 D 验收](../verification/phase-d.md)。

全库集合和导出选项保存在插件配置中，见 [集合与索引配置](collections.md)，不改变笔记 v1 字段。

阶段 F 批注扩展沿用 v1，增加可选 `note` 与 `noteRef`，原必需字段及规则保持不变。格式决策、标准脚注和继承规则见 [批注格式](annotations.md)。

展示配置与标注格式独立。围栏参数、全局默认值、会话折叠和 diff 复制规则见 [代码展示与 diff](code-display.md)。

第三方围栏参数直接参与展示，语义元数据独立保存。字段优先级、行选择规则、扩展字段与样例见 [参数对照](fence-parameters.md)。

Highlightr、Hilo 与代码行参数可通过独立窗口迁移，预览和逐文件恢复格式见 [迁移说明](migration.md)。迁移记录独立于笔记 v1 和插件配置 schemaVersion 2。
