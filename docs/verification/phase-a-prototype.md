# 阶段 A 首轮原型验证

日期：2026-11-14。版本：0.1.0。阶段 A 状态：进行中。

## 本轮交付

- 桌面插件骨架、manifest、MIT 许可、锁文件、lint/typecheck/build 和 CI。
- Markdown AST 结构解析，区分正文、代码、注释和 frontmatter。
- 正文局部换色、移除、同一高亮内多选区变换。
- 代码整行及精确文本标注，HB 注释持久化、quote 重定位。
- CodeMirror 行/文本装饰、保留语法 token 的阅读代码渲染。
- 四种语义命令、右键菜单、当前笔记侧栏、跳转和基础摘录。
- 项目测试 Vault 与 Electron 接口级宿主测试。

## 已执行的验证

`pnpm check` 通过：lint、类型检查、20 项逻辑/DOM 测试和构建。

`pnpm test:host` 通过：Obsidian 1.15.0 运行包、Electron 38.8.6、项目独立用户目录和测试 Vault，共 23 项宿主断言。原始结果见 [host-results.json](host-results.json)。

宿主断言覆盖加载、桌面标识、正文局部改色、撤销和重做、代码精确选区、编辑器装饰、代码行标记、callout/列表内代码、统一侧栏、来源跳转、阅读装饰、代码文本与语法 token 保留、Source/Live Preview 切换、插件启停和持久元数据读取。

DOM 测试另覆盖跨 token 精确强调、多行注释 token、空行及重复渲染幂等。代码解析测试覆盖 CRLF、Tab、中文、emoji、多长度围栏和嵌套容器。

本轮宿主证据为接口断言与 DOM 内容；可视截图验收继续留在后续阶段。

## 本轮修正

正文局部改色保留两侧颜色和 Markdown。代码标注只写围栏外的元数据，代码原字符保持一致。阅读装饰分割 token 时保留祖先样式节点。

文本和新选区合入一次 Editor.transaction，保持同一动作的编辑历史。真实宿主测试还捕获到将首字符替换为相同字符的同步事件；现将文本不变且没有效果变更的事务排除出历史，测试显式复现该事件后验证一次撤销与重做。阅读视图测试按宿主虚拟化滚动位置触发对应内容渲染后检查结果。

## 当前格式结论

HB v1 草案将 `from/to` 统一为代码内容的 UTF-16 偏移，quote、prefix、suffix 用于重定位。记录包含独立标注 ID、代码块 ID、语义及颜色快照。JSON 中的 `%` 转义，保持 Markdown 注释边界完整。

该草案已在顶层、callout、列表中完成首轮功能验证；正式冻结前继续验证重复块、代码内容改写、复制块和迁移。
