# 产品范围与需求

## 1. 目标体验

选中重点 → 赋予语义 → 添加解释 → 在侧栏找到 → 回到原文或代码 → 生成可复用摘录。

对象统一为 `prose`、`inline-code`、`code-line`、`code-range`。语法着色是代码展示能力，人工标注是知识记录能力。

开发与验收范围为桌面端。正式版发布前不承诺移动端支持，正式版之后根据需求另行评估。功能阶段验证正确性与交互，全部计划功能完成后统一测试和优化性能。

## 3. 选区与命令规则

### 正文

- 新选区：包装原生高亮；与相邻同语义片段按语法边界合并。
- 已高亮片段内空光标：作用于整个当前片段。
- 局部选区改色：拆分旧高亮，保留两侧颜色及内容。
- 选区覆盖多种颜色：统一选中范围，边界外的片段保留。
- “应用语义”始终设置目标语义；“切换高亮”单独提供切换行为。
- 跨段选区：按段生成独立片段；表格、列表和 callout 按所在结构分段。
- 行内代码作为独立范围，可用底线或边框强调；其中 `==` 保持代码含义。
- 行内代码整体作为标注单位，部分选区和内部空光标均作用于整段；语义注释紧贴闭合反引号，源字符保持原样。

### 代码

- “标记所选文本”使用精确字符范围；“标记所选行”扩展到逻辑行。
- 空光标执行行标记时作用于当前代码行；文本标记命令要求有效文本范围。
- 代码块内部使用代码标注格式；代码中的 `==`、反引号和标签保持原样。
- 跨代码块或正文/代码混合选择：按对象分组生成同一次操作，各自使用对应格式。
- 跨行文本标记按每行范围存储；Tab 以原始字符计数，显示宽度交给编辑器。
- 同一范围再次应用相同语义更新既有记录；移除命令只移除标注。
- 多条标注交叠时保留各条记录，通过底线、左侧边条和侧栏显示其身份。

## 4. 语义与配色

内置预设只是起点，用户可修改名称、图标、颜色和默认样式。普通正文原生颜色可独立使用；需要持久语义身份时创建标注记录。改变主题色影响显示，改变语义颜色映射可选择只更新预设或同步已有正文颜色。

`default` 表示跟随主题，`yellow` 表示显式黄色。预设 ID 保持稳定，改名更新展示字段；删除预设后已有条目保留其语义快照，用户可重新映射。

## 5. 摘录规格

提供“复制所选代码”“复制带上下文摘录”“生成摘录笔记”三类动作。代码复制输出源代码文本。摘录含文件路径、标题链、代码语言、代码块内行号、语义和批注；链接优先采用已有块 ID，其次标题链接，并附文本锚点供插件内定位。

支持保留原格式、纯文本、引用块和代码围栏模板。摘录笔记默认生成快照，重新生成由用户执行；动态查询视图列为后续可选能力。

## 6. 首版完成标准

在同一篇含正文、行内代码、C/Python/ASM 代码块的笔记中完成标记、改色、移除、撤销、重做、跳转和摘录；重启后标注恢复。桌面编辑、阅读和 Source 模式有对应验收记录。
