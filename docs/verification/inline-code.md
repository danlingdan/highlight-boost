# 行内代码实现与验证

日期：2026-11-14。桌面原型 0.1.0；宿主 Obsidian 1.15.0 运行包，测试进程 Electron 38.8.6。

## 本轮完成

- 新增 `inline-code` 对象及紧邻代码的 `hbi` v1 标注格式，保存身份、颜色、语义 ID 和名称快照。
- 使用现有语义和颜色命令应用、改色及移除；部分选区和空光标均作用于整段行内代码。
- 连续或分离选区同时处理正文、行内代码与代码块，保留代码源字符及一次撤销。
- 编辑器装饰、Live Preview 元数据折叠、阅读显示、侧栏跳转及摘录接入。
- 重复代码按来源对应；复制标注后再次编辑时更新副本身份。
- 跨行显示值与源范围分别处理，阅读映射覆盖完整源行区间。
- 表格通过正常宿主事务异步提交，保留原生撤销与重做。

格式和使用规则见 [行内代码 v1](../formats/inline-v1.md)。正文的持久语义记录继续作为下一项核心功能。
