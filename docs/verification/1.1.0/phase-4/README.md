## 本轮修复

- 外部 Shiki 插件负责语法渲染时，保留 HB 标注、批注与统一标题栏。
- 工具栏打开色板后保留键盘焦点；嵌套创建集合完成后返回原编辑位置。
- Escape 取消菜单后返回触发按钮，执行菜单动作后由对应动作管理焦点。
- 减少整行与精确标注重叠的背景叠色，保留语法前景与精确下划线。深浅色的 98 组代码颜色组合及正文、行内代码共 102 个对比度样本达到 4.5:1。
- PDF 保留整行颜色和完整批注，隐藏复制及编辑按钮和空标题栏。
